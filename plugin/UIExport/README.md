# UI Export（Photoshop プラグイン）段階 2: 解析と表示、名前の修正

開いている PSD のレイヤー名の印を読み、Unity 用の構造と、エラー・注意・提案をパネルに出す。
レイヤー名を変えるだけで直せる提案には「適用」ボタンが付く。PSD を変えるのはこのボタンを押したときだけで、変えるのはレイヤー名だけ。

## 読み込み方（UXP Developer Tool）

1. Photoshop を起動し、環境設定 > プラグイン で「開発者モードを有効にする」をオンにする（変えたら Photoshop を再起動）
2. （リポジトリから使う場合は、このフォルダをそのまま使う。移動しなくてよい）
3. UXP Developer Tool で「Add Plugin」を押し、このフォルダの `manifest.json` を選ぶ
4. 一覧に出た「UI Export」の行の「•••」（Actions）から「Load」を押す
5. Photoshop にパネルが出る。出ない場合は、プラグイン メニュー > UI Export

コードを変えたときは、UXP Developer Tool で「Reload」を押す。「Load & Watch」で読み込むと、保存するたびに自動で再読み込みされる。

## 使い方

1. PSD を開いて「解析」を押す
2. 「問題」タブ：エラー・注意・提案を一覧する。項目かレイヤー名を押すと、そのレイヤーが選択される
   - 上の件数を押すと、その種類の表示・非表示を切り替えられる（情報は最初は非表示）
3. ボタンが付いている項目は、押すとレイヤー名を直して自動で解析し直す（Photoshop の取り消しで 1 回で戻せる）
   - _Prefab / _Grp / _List / _Base を付ける、綴りの揺れを直す、名前の重複に連番を付ける、など
   - 位置や並び、グループの作り直しが要るものはボタンが無い。項目を押してレイヤーを選び、手で直す
4. 手で直したら、もう一度「解析」を押す
5. 「構造」タブ：Unity でどういう階層になるか（List、Prefab、まとめた画像、画面端への固定など）を見る

結果が思った通りでないときは、「確認用」タブの「解析結果を保存…」で JSON を保存して送ってください。

## area_ の対応付け（表示・非表示に関係なく、領域の指定として使う）

1. 名前がそれを含むグループの ID と同じ（`area_PlayerLv` → `PlayerLv_Grp`）: そのグループの領域
2. 名前が同じ階層の画像レイヤーと同じ（`area_Icon_A` → `Icon_A`）: その画像の枠
3. 文字レイヤーのすぐ下にある: その文字の枠
4. それ以外: それを含むグループの領域（文字 1 つだけを囲んでいるものは並べ忘れとして注意を出し、使わない）

画像の枠と `_Img` の領域は、書き出す画像の大きさにもなる（絵の周りは透明）。

## ファイル

- `manifest.json` プラグインの設定
- `index.html` / `style.css` / `main.js` パネル
- `ps/read.js` Photoshop からレイヤー情報を読む部分
- `core/analyze.js` 解析（Python 版 psd_to_layout.py と同じ判定。照合済み）
- `core/fixes.js` 名前で直せる提案の修正案
