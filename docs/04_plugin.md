# 04 Photoshop プラグイン（UXP）

## 段階

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 1 | 解析と表示（問題の一覧、構造ツリー、項目を押すとレイヤーを選択） | 完成 |
| 2 | レイヤー名で直せる提案の「適用」ボタン（PSD を変えるのはレイヤー名だけ。取り消し 1 回で戻る） | 完成 |
| 3 | 書き出し（画像・layout.json・report.html・history.json・preview.png、XMP の版、保存） | 未着手 |

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 設定（manifest v5、Photoshop 23.3 以上、ファイルの読み書きの許可） |
| `index.html` / `style.css` / `main.js` | パネル |
| `ps/read.js` | Photoshop からレイヤー情報を読む（読むだけ） |
| `core/analyze.js` | 解析（Python 版と同じ判定。Photoshop に依存しない） |
| `core/fixes.js` | 名前で直せる提案の修正案（Photoshop に依存しない） |

## 開発の進め方

1. Photoshop の 環境設定 > プラグイン で「開発者モード」をオンにする
2. UXP Developer Tool で「Add Plugin」→ `plugin/UIExport/manifest.json` を選ぶ → 「Load」
3. 「Load & Watch」にすると、ファイルを保存するたびに自動で再読み込みされる
4. 確認用タブ: 「解析結果を保存…」（読んだレイヤー情報と結果の JSON）、「読み取りの比較」（2 つの読み取り方式の照合）

## 読み取り

- 速い方式: `multiGet` で全レイヤーの必要な項目を 1 回で取る（約 100 レイヤーで 0.1 秒未満）
- 遅い方式: DOM でレイヤーごとに問い合わせる（約 6 秒）。速い方式が失敗したときだけ使い、知らせる
- 並び: Photoshop は上から、解析は下から（Python 版と同じ）
- グループの範囲は使わない（解析で中身から計算し直す）

## UXP で分かったこと（実機で確認）

- **モジュールの中から別モジュールを相対パスで `require` しない**（環境によって解決の基準が違う。`main.js` から読むのは問題ない）
- `textarea` の中身は `value` で設定する（`textContent` では表示されない）。表示だけなら `div` を使う
- `sp-button`（標準のボタン）は背景色を変えられない。色を指定したいボタンは自前の `div` で作る
- グループを選ぶだけでは、レイヤーパネルで親のグループが開かない。中の画像レイヤーを先に選んでから、グループを選び直す
- 名前の変更は `executeAsModal` の中で行い、`hostControl.suspendHistory` で取り消し 1 回分にまとめる
- 解析した後に名前が変わっていないかを、変更の前に確かめる（変わっていたら変更せず、解析し直してもらう）
- Photoshop の文字の範囲はフォントの更新で変わることがある（別の PC で開いたときなど）
- ドキュメントの解像度が 72 以外でも、文字の大きさは px に直して出す（96dpi の PSD で確認）

## パネルの見た目（ユーザーが決めた値）

| 項目 | 値 |
| --- | --- |
| 文字の大きさ | 18px が既定。上部の A− / A＋ で 2px ずつ（10〜32px、次回も覚える） |
| パネルの背景 | `#404040`（明度 25%） |
| 見出し | 本文より約 1.2pt 大きい（1.09em）、太字。「提案：グループ指定」のように種類の短い説明を付ける |
| エラー / 注意 / 提案 / 情報の色 | `#E5484D` / `#FFBB33` / `#00D5FF` / `#A6A6A6`（明度 65%） |
| 本文中のレイヤー名（リンク） | `#00FFFF`、太字、枠線なし。押すとそのレイヤーを選ぶ |
| 修正ボタン | 背景 `#262626`（明度 15%）、白い枠、角丸。マウスを乗せると白く塗って文字を黒に |
| 文字の大きさ | 本文・「対象:」・名前の変更の見本はすべて同じ大きさ（見出しだけ大きい） |

- 本文中の名前は名前だけを出す（親のパスは出さない）。同じ名前が複数あって区別が要るときだけ `親 / 親 / 名前` の形にする
- 本文に出てこない対象は「対象:」の下に 1 件ずつ改行して並べる
- 名前の変更の見本も 1 件ずつ改行する
- 見出しの 1 行目（ファイル名）と 2 行目（時間の内訳）は分ける。内訳は省略しない

## 名前で直せる提案（`core/fixes.js`）

| 問題 | ボタン |
| --- | --- |
| Prefab 候補 | 候補のグループ全部に `_Prefab` を付ける |
| 印が無いので外したグループ | `_Grp` を付ける |
| 1 枚にまとめた画像だけのグループ | `_Grp` / `_List` を付ける（2 択） |
| 一番下の画像が親とほぼ同じ大きさ | `_Base` を付ける |
| 等間隔に並んでいる（グループ全体が並び） | `_Grp` を `_List` に変える |
| 綴りの揺れ | 同じ綴りを含むレイヤーを全部直す |
| ID に使えない文字 | 使えない文字を `_` にする |
| 同じ階層での名前の重複 | 左から `_1`, `_2`…（印の無いグループを外した結果の重複は対象外。親に `_Grp` を付ける方が正しい） |
| 文字枠の並べ忘れ | 名前を `area_<グループ ID>` にしてグループの領域にする |

位置や並び、グループの作り直しが要るものはボタンを付けない（レイヤーを選んで手で直す）。
