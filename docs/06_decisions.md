# 06 決定の記録（理由つき）

| 決めたこと | 理由 |
| --- | --- |
| 全部を自動判定せず、印で明示する。ツールは抜けを「提案」として出す | 複雑な PSD では自動判定が多すぎて扱えない。間違いは必ず出るので、一覧にして直せるようにする |
| `_Comp` をやめる | AE のコンポジションは Unity の構造から決まる |
| area_ / space_ は表示・非表示に関係なく構造の情報 | 見せたいかどうかと構造は別の話 |
| 文字の枠は「文字レイヤーのすぐ下の area_」で対応付ける | 位置での判定はずれに弱い。文字レイヤーの名前は自動で付くので名前では対応できない |
| 画像・グループの area_ は名前で対応付ける | 並び順で広げると、グループの一番下に置く領域の area_ とぶつかる |
| 効果は画像レイヤーでは焼き込み、必要なものだけ `_Fx` | 常に分けると画像と階層が増える。個別に動かすものだけ分ければよい |
| 直すのは PSD だけ。report.html は読むだけ | 直す場所が 2 つあると、どちらが正しいか分からなくなる |
| エラーがあっても書き出せる。止めるのは Unity の取り込み | 書き出しはダブルチェックと相談に使う。取り込みが最終決定 |
| UIExport は Unity プロジェクトの中、Assets の外 | 共有は git、Unity には読み込ませない |
| 版は書き出し時に付ける。PSD の XMP に「元にした版」 | 保存のたびに付けると無意味な版が増える。複製しても続きと分かる |
| シェイプはベクトルの範囲で測る | ピクセルの範囲はアンチエイリアスで 1〜3px 大きくなる。属性パネルの値がデザイナーの意図 |
| グループの範囲は中身から計算し直す | Photoshop の値は非表示レイヤーを含む・空だと異常値になる |
| 読み取りは multiGet で 1 回にまとめる | レイヤーごとの問い合わせは約 900 回の往復で 6 秒かかった |
| 「提案」のうちレイヤー名で直せるものだけボタンにする | 名前の変更は安全で、取り消しも簡単。位置や構造の変更は人が判断する |
| プラグインの残りは Claude Code、Unity ツールは Claude Code の IDE 拡張で作る | zip の受け渡しをなくす。Unity ツールはプロジェクトの中で書いて試す必要がある |
