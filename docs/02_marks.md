# 02 印の規則（PSD 側）

## 名前の末尾の印（重ねて付けられる。Unity 上の名前からは外す）

| 印 | 付ける先 | 意味 |
| --- | --- | --- |
| `_Grp` | グループ | GameObject として残す（大きな親も、ボタンやバッジなどの小さな部品も） |
| `_List` | グループ | LayoutGroup。直下の子は印が無くても並びの項目になる。向きと間隔は位置から判定 |
| `_Prefab` | グループ | Prefab にする。`_Grp` / `_List` に重ねる。単独なら `_Grp_Prefab` とみなす。`_Pf` も可 |
| `_Img` | グループ | 中身ごと 1 枚の画像にする（文字やレイヤースタイルも焼き込む） |
| `_Base` | レイヤー / `_Img` グループ | 親（`_Grp` / `_List`）自身の Image になる。子としては作らない |
| `_Fx` | レイヤー / `_Img` / `_Base` | レイヤースタイルを焼き込まず、別の画像に分ける（**未実装**。下の「効果」を参照） |

`_Comp` は使わない（AE のコンポジションは Unity の構造から決まるため、印は要らない）。

## 印の無いグループ

- 画像だけ → 自動で 1 枚の画像にまとめる（「自動でまとめた画像」としてレポートに出る）
- 文字や印付きを含む → グループを外し、中身を一番近い印付きの親に入れる

外したグループやまとめたグループが部品らしい場合（ボタン名、画像と文字の組み合わせ、数字を含む、
画面の大きな区画、同じ大きさの画像の等間隔の並び）は、`_Grp` / `_List` を付ける提案を出す。

## area_（領域の指定）

名前の先頭が `area_`。**表示・非表示に関係なく**構造の情報としてだけ使い、画像にはしない。対応付けは上から順に判定する。

1. 名前がそれを含むグループの ID と同じ（`area_PlayerLv` → `PlayerLv_Grp`。大文字小文字は区別しない）: そのグループの領域
2. 名前が同じ階層の画像レイヤーと同じ（`area_Icon_A` → `Icon_A`）: その画像の枠
3. 文字レイヤーの**すぐ下**にある: その文字の枠（文字レイヤーの名前は中身から自動で付くので、名前ではなく並び順で対応付ける）
4. それ以外: それを含むグループの領域
   - ただし、枠の無い文字 1 つだけを囲んでいるものは「並べ忘れ」として注意を出し、使わない
   - グループの領域が 2 つ以上あれば注意を出す

位置は対応付けには使わず、検査にだけ使う（文字のはみ出し、並べ忘れの検出）。
グループと同じ名前の area_ がそのグループの外にあれば「中に入れる」注意を出す。

画像の枠・`_Img` の領域・まとめた画像の領域は、**書き出す画像の大きさ**にもなる（絵は PSD の位置のまま、周りは透明）。
焼き込んだ効果が枠からはみ出したら、切らずに広げて注意を出す（「枠を広げるか、`_Fx` で分ける」）。

### 検討して採らなかったこと

- 位置（文字の中心が area_ の中にあるか）で対応付ける → ずれていても対応してしまう、ずれると黙って別の解釈になる
- 文字以外にも「すぐ下の area_」を広げる → グループの一番下に置いたグループの領域（よくある置き方）とぶつかる

## space_（間隔・余白・画面端からの距離）

名前の先頭が `space_`。表示・非表示に関係なく構造の情報としてだけ使う。

| 置き方 | 意味 |
| --- | --- |
| `_List` の項目と項目の間 | 間隔（spacing） |
| `_List` の端と項目の間 | 内側の余白（padding） |
| `_List` 以外の容器（画面全体を含む）の端と部品の間 | その端に固定（アンカー）し、距離をその値にする |

片側だけ部品に接している、どこにも接していない、実際の距離と違う、などは注意を出す（許容差 3px）。

## 位置と大きさの測り方

- シェイプ（ベクトル）: ベクトルの範囲（Photoshop の属性パネルの値）。シェイプの線（レイヤースタイルではない）は含める
  （中央揃えなら線幅の半分、外側なら線幅）。アンチエイリアスのにじみは含めない
- グループ: 表示されている中身（area_ / space_ を除く）を合わせた範囲で計算し直す
  （Photoshop が返すグループの範囲は、非表示のレイヤーを含んだり、空のグループで異常な値になったりするため使わない）
- 文字: Photoshop の値。フォントの更新で数 px 変わることがある

## 並び（_List）

- 同じ大きさで一列に並んだ項目を探し、向き・間隔・余白を決める。間隔が揃っていなければ注意を出す
- バッジなどのはみ出しで 1 つだけ大きい項目は、ほかの項目の枠にそろえる（提案: 項目全体の area_ を置く）
- LayoutGroup が制御するのは直下の子の位置と大きさだけ。項目を個別にアニメーションさせる場合だけ「枠 + 見た目」の 2 段にする

## Prefab

- `_Prefab` を付けた同じ親の中のグループを 1 つの Prefab とし、構成の違い（差分）を出す
- 印は無いが同じ構造のグループが並んでいれば Prefab 候補として提案する

## 効果（レイヤースタイル）

分けられる効果: ドロップシャドウ・光彩（外側）・光彩（内側）・境界線。ベベル・サテン・パターン・描画モードは常に焼き込む。

| 効果が付いている場所 | 扱い |
| --- | --- |
| `_Grp` / `_List` のグループ | 常に別画像に分ける |
| 普通の画像レイヤー・`_Img`・`_Base` | 焼き込む。`_Fx` を付けたときだけ分ける |

分けたときは、外側の効果は絵の後ろ、内側の効果は前に置き、Glow / Art / Stroke を包む入れ物を作る。
光彩は白で書き出し、色・不透明度・描画モードを記録する（Unity 側で色を変えられるように）。
文字の境界線・影は TextMeshPro のアウトライン・影にする。（**ここは未実装**）

## 名前の検査

- 同じ階層で名前が重複（エラー）、ID に使えない文字（エラー）、既定の名前（情報）
- 綴りの揺れ（注意）、別の場所の名前の流用（注意）、入れ子での名前の重複（注意）
